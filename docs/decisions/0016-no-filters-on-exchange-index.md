# 0016 交換会一覧に絞り込みを置かない

- 日付：2026-08-21（この記録に集めた日。決めたのは #132 の時点）
- 発端：#183（元は `docs/spec.md` 6.6 に織り込まれていた経緯）

## 決めたこと

交換会一覧に絞り込みを置かない。フェーズでも、自分が主催しているかどうかでも絞れない（6.6）。
この画面が答えるのは「どれを開くか」までで、探す画面ではない。

判断は2つの前提に乗っている。1つは参加数が多くても十数件という見積もり（10.）で、
これは規模が変われば崩れる。もう1つが下の2つで、規模とは無関係に残る。

## なぜ

- **フェーズで絞ると、カードの強さの3段階が意味を失う。** 希望提出期間だけに絞れば
  朱の面と朱の文字しか残らず、ざっと見て1枚だけが目に飛び込む作りが成り立たない。
  締切の近い順に並べているのは、いちばん急ぐものを上に押し出すためだが、絞り込みは
  その1枚を画面の外へ出せる道具でもある。締切を見落とさせないための並びと、
  並びから外す口が、同じ画面に載ることになる
- **主催しているかどうかでの絞り込みは、主催と参加を区別せずに並べる決めごとに触れる**（6.8）。
  主催かどうかはカードが「主催 あなた」で示しており、主催者としての仕事は交換会ページの
  主催者管理から入る（6.1）。一覧で主催だけを取り出しても、そこから先の行き先が増えるわけではない

## 却下した代替案

- **フェーズと主催で絞り込めるようにする**（#132 が置こうとしていた形）— 上の2つのため
- **終了したものを畳む口を置く** — いまは置かないが、前提（十数件）が崩れたときに
  まず当たるのはこちらになる。判断は `0010`（「交換会一覧の「終了した交換会（3）」」）にある

## 影響する場所

- `docs/spec.md` 6.6
- `app/controllers/exchanges_controller.rb` の `index`（絞り込みのパラメータを取らない）
- ビジュアルガイドの採否は 0010 にある
