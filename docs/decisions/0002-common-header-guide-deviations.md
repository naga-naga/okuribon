# 0002 共通ヘッダーでビジュアルガイドから採らなかったもの

- 日付：2026-08-21（この記録に集めた日。各項目を決めたのは #81 / #91 / #134 の時点）
- 発端：#182（元は `docs/spec.md` 10.2「ガイドから採らなかったもの」）

## 決めたこと

共通ヘッダーについて、ビジュアルガイドの描き方を以下の8点で採らない。
共通ヘッダーは画面をまたぐので、ガイドのファイル1つには対応しない。

## 項目

### 共通ヘッダーの中身

**決めたこと** — 左をパンくず、右をアカウント（利用者とログアウト）で通す。
画面ごとに中身を変えない

**なぜ** — 資料は全画面にアバターの丸を描きながら、押した先を一度も描いていない。
ログアウトの口がどこにも無く、それが共通ヘッダーを入れる第一の理由（#81）なので、
右はアカウントに充てた

**却下した代替案** — 資料の帯は、左が「1つ上へ戻る口＋現在地」、右が
「その画面の本文に無い、いちばん大事なもの」になっている。交換会ページは締切を本文で
大きく出すので帯の右は交換会一覧への口、本の登録フォームと主催者管理は本文に締切が
無いので帯の右が残り時間、という具合に画面ごとに中身が変わる

### 共通ヘッダーの残り時間

**決めたこと** — 共通ヘッダーに残り時間を置かない

**なぜ** — 締切を出すのは交換会ページの状態ヘッダーの仕事で、スクロールしても
畳んだ帯に残る（6.1）。主催者管理は実行の区画が持っている（6.8）。
共通ヘッダーにも出すと、同じ数字が1画面に2か所並ぶ

**却下した代替案** — 資料は本の一覧・本の登録フォーム・主催者管理の帯に
「登録期間 残り 6日 3時間」を出す

### 共通ヘッダーの主催者バッジ

**決めたこと** — 置かない

**なぜ** — h1 が「主催者管理」で、そもそも主催者しか開けない画面なので、
誰が見ているのかを共通ヘッダーで言い直す用がない

**却下した代替案** — 資料は主催者管理の帯に「主催者」のチップを置く

### 共通ヘッダーの幅

**決めたこと** — 全幅の共通ヘッダーにし、内側は本の一覧に合わせた 1180px で通す

**なぜ** — 本文の幅は画面ごとに 560〜1180px と違うため、本文へ揃えるには
各ビューが幅をもう一度宣言することになり、container の指定と二重になって
片方だけ動く。広い画面で本文の狭い画面を開くと共通ヘッダーの左端が本文より
外に出るが、モバイルでは常に揃う（11.）

**却下した代替案** — 資料は帯を画面のカードの中に描くので、幅が必ず本文と揃う

### 共通ヘッダーのパンくず

**決めたこと** — 祖先を連ねる。現在地はパンくずに入れない

**なぜ** — 画面の名前は h1 にあるので、共通ヘッダーにも並べると
同じ名が1画面に2か所出る

**参照できるもの** — 資料に対応するものが無い。資料の帯は「← 交換会一覧」のように
1つ上への口を1本持つだけで、祖先が2段ある画面（本の登録フォーム、実行の確認、
交換会の編集）でも1段しか出さない。参照できるものが無かったので、
採否ではなく補いにあたる

### サービス名

**決めたこと** — 「おくりぼん」にする（1., #134）。
**採らないのは名前だけで、見出しに大きく出すという扱いのほうは資料のとおり採る**

**なぜ** — 資料が置いているのは一般名詞で、画面に並ぶ交換会名
（「冬の読書交換会 2026」）と語がぶつかる

**却下した代替案** — 資料は 01 の見出しにも 02 / 03 / 08 の帯にも
「読書交換会」を置く

### 共通ヘッダーの帯にサービス名を置くこと

**決めたこと** — 名前を置くのは、根が行き先を持たない未ログインのときだけ

**なぜ** — ログイン済みの画面ではパンくずの根が行き先の名前（「交換会一覧」）を
名乗る（5.）。資料の帯は祖先を1段しか持たないので、左に置けるものが名前しか
無かった。祖先を連ねる実装では、根も画面の名前で揃う

**却下した代替案** — 資料の 02 / 03 / 08 は帯の左にサービス名を置く

### 交換会の中のサブナビ

**決めたこと** — 置かない

**なぜ** — #81 は「どの画面からでも他の画面へ行ける」導線を求めるが、
交換会ページの状態ヘッダーが各画面への導線を持っている（6.1）ので、
共通ヘッダーにタブを足すと同じ導線が1つの交換会に2か所できる。
統合で交換会の中の画面は交換会ページ・本の登録フォーム・結果画面・主催者管理の
4つに減り、後ろの3つはどれも交換会ページから1手で届く

**参照できるもの** — 資料も横に並ぶタブを持たない。採否ではなく、
#81 の求めに対する判断にあたる

## 影響する場所

- `app/views/layouts/_header.html.erb`
- `config/locales/ja.yml` の `service.name`（1.）
