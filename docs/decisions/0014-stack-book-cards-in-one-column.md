# 0014 本のカードは縦1列に積み、その場で開く

- 日付：2026-08-21（この記録に集めた日。決めたのは #95 / #127 の時点）
- 発端：#183（元は `docs/spec.md` 6.2 に織り込まれていた経緯）

## 決めたこと

- 本のカードは5フェーズとも縦1列に積み、横には並べない（6.2）
- 気になった1枚はその場で開く。1冊だけを開く画面へは飛ばさない（6.3 / `0015`）
- 何行に折れるかはブラウザで測る。伏せた状態で描いておき、測ってから開く口を出す（6.2）

## なぜ

1列なら開いても下が押し下がるだけで、横は動かない。読み比べの途中で
どこまで見たかを見失わせないためで、詳細画面へ飛ばさない理由と同じところに乗る。

## 却下した代替案

- **3カラムに並べ、開いた1枚を全幅に広げる** — 以降のカードがマスの中で総入れ替えになり、
  詳細画面へ飛ばしたときと同じものを、同じ画面の中で失う
- **3カラムに並べ、マスの中で縦に伸ばす** — 同じ行のカードが開いた1枚の高さまで
  引き伸ばされ、本文と下段のあいだに何も無い面が空く
- **折るのをやめて全文を出してから測る** — 十数枚が一度伸びてから畳まれるので、
  開いた直後の画面が跳ねる。伏せたまま測る側を採り、JavaScript が動かない環境で
  本文が折られたままになることのほうを引き受けた（6.2）
