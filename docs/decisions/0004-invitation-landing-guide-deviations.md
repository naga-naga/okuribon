# 0004 招待URL着地画面でビジュアルガイドから採らなかったもの

- 日付：2026-08-21（この記録に集めた日。各項目を決めたのは #15 / #93 の時点）
- 発端：#182（元は `docs/spec.md` 10.2「ガイドから採らなかったもの」）

## 決めたこと

招待URL着地画面（6.7、ガイドの `ログイン・招待・交換会一覧.dc.html`）について、
資料の描き方を以下の3点で採らない。
参加ボタンの横に並ぶプロバイダ3つを採らない理由は 0003 にある。

## 項目

### 招待URL着地画面の参加者アイコン

**決めたこと** — 招待URLを知っているだけの人には人数だけを出す

**なぜ** — 参加者の顔ぶれが見えるのは参加者だけ（8.）

**却下した代替案** — 資料は参加人数の横にアバターを並べる

### 招待URL着地画面の日程の期間表記

**決めたこと** — 各段の開始日時を「◯◯から」で出す（6.7）

**なぜ** — 締切が日中にあるとき、範囲の右端に日付だけを書くと、
その日いっぱい使えるように読める

**却下した代替案** — 資料は「2/1 — 2/14」と範囲で書く

### 「招待URLは次回また使えるようになります」

**決めたこと** — 参加できないときの案内にこの一文を置かない

**なぜ** — 次の交換会は別の招待トークンを持つ。果たせない約束になる

**却下した代替案** — 資料は参加できないときの案内にこの一文を添える

## 影響する場所

- `app/views/invitations/show.html.erb`
