# 0005 本の登録フォームと本の詳細でビジュアルガイドから採らなかったもの

- 日付：2026-08-21（この記録に集めた日。各項目を決めたのは #21 / #23 / #91 の時点）
- 発端：#182（元は `docs/spec.md` 10.2「ガイドから採らなかったもの」）

## 決めたこと

ガイドの `本の登録フォームと詳細.dc.html` について、
資料の描き方を以下の2点で採らない。

## 項目

### 本の登録後の着地先

**決めたこと** — 既定は交換会ページへ戻す。フォームに `continue` の submit を
別に置き、資料の流れも残した

**なぜ** — 1冊登録して終わる人のほうが多く、続けて登録する人には口を別に用意すれば足りる

**却下した代替案** — 資料は「登録して、続けてもう1冊」でフォームに留まる。
採らなかったのは既定にすることだけで、流れそのものは submit を分けて残している

### 本の詳細画面そのもの

**決めたこと** — 持たない（6.3）。資料の 05 にある「前の本 ／ 次の本」の送りも、
行き先の画面ごと採らない

**なぜ** — 05 が載せる情報は 6.2 のカードを開けば全部揃い、
06 のコード開示は 6.5 と二重になる。資料の 06 もヘッダーが「← 結果画面」で、
結果画面から1クリック先へ置いただけの位置にある

**却下した代替案** — 資料は 05（他人の本）と 06（受け取った本・コード開示）で
1冊だけを開く画面を描く

## 影響する場所

- `app/views/books/_form.html.erb`
- `app/views/books/new.html.erb`
- `app/views/books/_list.html.erb`（詳細を持たないぶんカードが受け持つ）
